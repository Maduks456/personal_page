# Personal Page
## About
<p>
    It's a web page that's for me to show users what kind of projects I have created or plan to make. The user can see the projects status, description, if the project has you can see Github repository link, tags and image
</p>
<p>
    Built with Laravel.
</p>

## Features
<ul>
    <li>
        Give accounts a profile picture (That broke when putting the project to vercel)
    </li>
    <li>
        Make Pojects/ Tags (The creators account)
    </li>
    <li>
        Edit Pojects/ Tags (The creators account)
    </li>
    <li>
        Delete Pojects/ Tags (The creators account)
    </li>
    <li>
       View all Pojects/ Tags 
    </li>
    <li>
       View a single Poject
    </li>
    <li>
        View About me page
    </li>
    <li>
        View Hall of fame page
    </li>
    <li>
        View Home page
    </li>
</ul>
